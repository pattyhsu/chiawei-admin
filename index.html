收據產生器 →
開立學費收據，四個分校共用一個版型；大寫金額自動換算，直接列印或存成 PDF。
諮詢名單 →
官網「預約免費檢測」表單送出的家長名單：電話、孩子年級、想加強的科目。 聯絡後改狀態（待聯絡 → 已聯絡 → 已約檢測 → 結案），含個資、不對外。
名冊 →
班級、學生、誰教哪一班。出考卷和批改都以班級為單位，所以名冊是它們的來源。 老師為唯讀、只看得到自己任教的班。
課表 →
頭份每週課表（115學年，8/24 起）：各班時段與授課老師，可直接列印或存成 PDF。
老師日誌 →
一班一天一則：今天教到哪、出了什麼作業、班上狀況。 老師寫自己的班；負責人和主任看得到全部。
點名單 →
選班級印出點名表格：學號、姓名、空白日期欄，上課手寫勾到。純列印，不記錄。
老師帳號 →
建立老師登入、指派任教班級、停用離職帳號。密碼由系統產生、只顯示一次； 帳號一律停用而不刪除，過去的卷與批改紀錄才留得住。
開課資訊台 →
發布官網與家長專區的開課資訊：新班、時段、開課日。 「開課中」的班會直接公開顯示，下架用「已收班」。
出勤紀錄 →
櫃檯平板打卡（拍照存證）的紀錄與每月時數。老師和主任只看得到自己； 負責人看全部、可作廢與補登。
收費台 →
誰還沒繳、收費紀錄、每期班費與個人優惠。收錢在收據產生器「記帳並列印」， 這裡看帳；紀錄只能作廢不能改。
收費總覽 →
各分校每月實收、各期各班應收／已收／未收與收齊率。只有負責人看得到， 資料庫端強制。
內容行銷台 →
FB / IG / LINE 貼文：審核每日自動產生的草稿、下載卡片、複製文案， 也可以手動建立榜單、活動、見證、躍升卡。
